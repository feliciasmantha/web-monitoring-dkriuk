# D'Kriuk Web Monitoring System

## Project Overview
A web-based inventory monitoring system developed to support inventory management and monitoring for D'Kriuk franchise outlets.

## Features
- Web-based inventory monitoring.
- Inventory data management.
- Database integration using PostgreSQL.
- Web interface built with Flask and HTML templates.

## Technologies Used
- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS
- **Deployment Configuration:** Vercel

## Project Structure
- `app.py` — Main application.
- `config.py` — Application configuration.
- `database.py` — Database connection and operations.
- `templates/` — HTML templates.
- `static/img/` — Image assets.
- `vercel.json` — Deployment configuration.

## How to Run Locally
1. Install Python.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Configure the required environment variables for the database.
4. Run the application using the appropriate Flask command.

## Purpose
This project demonstrates the application of web development and database management to support inventory monitoring and operational data management.
